⚙️ Reglas técnicas clave
📐 Factor /100 en bonos
Bono Soberano, Dólar Linked, Bono CER y Bono Dual cotizan en centavos en el mercado ARS. Para calcular valor real: precio / 100. CEDEARs y Acciones usan precio directo.
💰 Cálculo MEP portafolio
Valor USD de posición = (precio_ars × cantidad) / mep. Se puede usar MEP de compra histórico (mep_compra) o MEP actual del día (AL30 ARS÷USD) para ver ganancia/pérdida.
⚡ Realtime — cómo funciona
El browser se conecta vía WebSocket a Supabase Realtime y suscribe al canal de la tabla mercado. Cada cambio llega sin polling. La evaluación de alertas ocurre inmediatamente en el browser.
🔐 Claves de acceso
Frontend usa anon key (pública, ok para lectura). Scripts Python usan service role key para writes masivos sin restricciones de RLS. Edge Function tiene JWT verification desactivado.
🎨 Sistema de temas
4 temas via data-theme en <html>. Variables CSS: --bg, --text, --green, etc. Tema persiste en localStorage. IBM Plex Mono para valores numéricos.

☁️ monitor-cron (edge function)
Una function con 8 tasks dispatched por { task }:
  • watchdog-ars — alerta Telegram si mercado stale >8min
  • watchdog-usa — idem para mercado_usa
  • dolar-snapshot — MEP (AL30/AL30D), CCL (AL30C), Oficial/Blue/Mayorista (dolarapi)
  • pnl-snapshot — calcula PnL por usuario → pnl_diario
  • resumen-telegram — resumen diario MEP/CCL/Oficial
  • earnings-watch — earnings próximos de ADRs del portafolio
  • health-check — yahoo-prices alive?
  • historico-refresh — mantiene historico_precios fresco
🐧 watchdog_restart.sh (WSL, local)
Lo único local — porque desde acá se ejecuta schtasks:
  • Cada 5 min lun-vie en horario de mercado
  • Si mercado stale >8min → wmic kill monitor_rt.py + schtasks /end + /run "\Dashboard"
  • Si mercado_usa stale >8min → kill alpaca_usa.py + restart "\Dashboard USA"
  • Mata antes de reiniciar (evita instancias Python duplicadas)
  • Log: scripts/watchdog_restart.log
📦 Scripts auxiliares
  • scripts/backfill_calendario.sh — rellena días faltantes en pnl_diario con posiciones activas + MEP histórico
  • scripts/backfill_mep.sh — backfill MEP histórico usando AL30D/AL30H de Yahoo Finance
  • scripts/load_short_volume.py — carga diaria short volume FINRA a cache_finra_short_volume
  • Backfill automático de dólar — monitor_local.sh al cierre (17:01-17:30) verifica si el día anterior tiene datos de MEP y oficial. Si falta alguno, ejecuta get_dolar con la fecha del día anterior usando date_art override. Fuentes: dolarapi.com (fallback principal), edge function yahoo-prices (AL30/AL30D), ArgentinaDatos (oficial), BCRA (fallback oficial).
