📘 Guía Short Data
📊 Short Volume % (diario)

¿Qué es? Porcentaje del volumen total del día que se operó como venta en corto.

Cómo leerlo:
>40% → presión corta muy alta
25-40% → presión corta elevada
15-25% → rango normal
<15% → baja actividad de cortos

📈 Percentil Histórico

Percentil 90+ → nivel extremo · 75-90 → alto · 25-75 → normal · <25 → bajo

📉 Short Interest (SI, bi-mensual)

SI subiendo + SV bajo → nuevos cortos = bajista · SI bajando + SV alto → cobertura = alcista

📐 Días para Cubrir

>10 días = squeeze potencial si hay catalyst.

Tasa Fed Funds — Histórico
📊 Cómo leer este gráfico: Las zonas grises son períodos de recesión según el NBER. La Fed sube tasas para enfriar la economía y las baja para estimular el crecimiento.
Curva de Rendimiento — Treasury 10Y vs 2Y + Spread
📊 Inversión de curva: Cuando el spread 10Y-2Y cae por debajo de 0 (línea roja punteada), la curva está invertida. Históricamente precedió a cada recesión en USA desde 1950 con un rezago de 6 a 18 meses.
Inflación: CPI Anualizado vs Breakeven 10Y
📊 CPI vs Expectativas: El CPI refleja inflación REAL pasada. El Breakeven 10Y refleja EXPECTATIVAS futuras. Cuando Breakeven > CPI → el mercado anticipa inflación al alza.
Desempleo USA vs Confianza del Consumidor
📊 Mercado laboral: Desempleo bajo + confianza alta = economía fuerte. Cuando el desempleo sube y la confianza cae simultáneamente, suele señalar inicio de recesión.
