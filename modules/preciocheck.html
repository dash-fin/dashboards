📚 Estructura datos:
• sucursales[].id → formato "24-2-2" (comercio-bandera-sucursal)
• productos[].id → código EAN (7790895001413)
• sucursales[].preciosProducto.precioLista → precio real del producto
• sucursales[].banderaDescripcion → nombre de la cadena
• sucursales[].actualizadoHoy → boolean si tiene precio actualizado

Flujo end-to-end:
1. Sucursales por lat/lng
2. Producto por nombre + lat/lng
3. Elegir producto → obtener precios en sucursales cercanas
4. Resultados ordenados por precio (más barato primero)
