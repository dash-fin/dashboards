Notas críticas de implementación
⚠️ Hermes Engine — Locale
NO usar toLocaleString('es-AR'), toLocaleDateString, toLocaleTimeString.

Hermes en Android no incluye datos de locale → TypeError: undefined is not a function.

Usar siempre formatters manuales con .toFixed(2) + regex /\B(?=(\d{3})+(?!\d))/g.
⚠️ Supabase Response Safety
Supabase puede devolver un objeto de error (truthy) en lugar de un array cuando hay error de red o de query.

value || [] no protege (objeto es truthy).

Usar siempre:
Array.isArray(v) ? v : []
🔑 Supabase Auth
JWT persiste en AsyncStorage entre sesiones.
detectSessionInUrl: false requerido para mobile.

Reset password: usa redirectTo con URL en uri_allow_list.
Site URL: https://dash-fin.github.io/dashboards
📦 Build pipeline
1. Editar screens en src/screens/
2. cd android && ./gradlew assembleRelease
3. adb install -r app-release.apk

No hay hot reload en release. Cada cambio = nuevo build (~3-5 min).
