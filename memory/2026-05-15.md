# 2026-05-15 — Migración monitoreo Windows → WSL

## Qué se hizo

### Creación de `monitor_local.sh`
Nuevo script bash para monitoreo del mercado ARS. Porta la sección ARS del `monitor_dashboard.ps1` original:
- Watchdog de precios en tabla `mercado` (10:40-16:59 ART)
- Captura MEP vía AL30/AL30D desde Rava edge function
- Captura dólar oficial (ArgentinaDatos → fallback BCRA)
- Captura CCL vía AL30/AL30C desde Rava
- Snapshot PnL portafolio (17:06-17:59 ART)
- Envía resumen diario a Telegram

**Sin secretos hardcodeados** — todo vía `SUPABASE_SR_KEY`, `TG_TOKEN`, `TG_CHAT_ID` desde entorno.

### Creación de `monitor_usa.sh`
Nuevo script bash para monitoreo del mercado USA:
- Watchdog de precios en tabla `mercado_usa` (08:10-20:30 ART)
- Health check de edge function `yahoo-prices`
- Earnings watch: consulta próximos earnings de ADRs en portafolio y alerta Telegram
- Flag system para evitar duplicados (por día + por ticker/fecha)

### Actualización de `arquitectura.html`
Agregada sección de monitoreo con:
- Diagrama de migración Windows → WSL
- 3 flows: `monitor_local.sh`, `monitor_usa.sh`, `load_short_volume.py`
- Crontab template completo
- Variables de entorno requeridas documentadas
- Instrucciones para desactivar Task Scheduler en Windows

### Legado
- `monitor_dashboard.sh` — se reescribió parcialmente pero quedó truncado. Borrarlo/revisarlo.
- `monitor_dashboard.ps1` — se mantiene como backup, se puede desactivar con `Unregister-ScheduledTask`
